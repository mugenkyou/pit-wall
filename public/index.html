The Pit Wall

Built and maintained by Sachin Patel.

GitHub → LinkedIn →

Pit Wall is a passion project built to give Formula 1 fans a faster, cleaner, and more immersive race-day experience. Instead of switching between multiple websites, Pit Wall brings live timing, telemetry, weather, standings, schedules, and race insights together in one dashboard.

I'm a Computer Science student who enjoys building products around AI, automation, developer tools, and motorsport. Pit Wall combines those interests into a project focused on speed, simplicity, and a great user experience.

If Pit Wall makes your race weekends better, then it has done exactly what it was built for.
